# AWS solutions

Solutions are keyed by **lab**, not by cloud. The GOAD attack path is the same
whether the range runs on AWS or GCP, so it is written once in
[the GOAD series](../goad/README.md) and is not copied per provider.

This folder holds only what is genuinely AWS specific: deploy quirks, console
steps, and any technique whose behaviour differs on this provider. Nothing here
yet. See [[goad-fidelity-build]].
